# APAAR verification limitations

Official APAAR verification unavailable — demonstration mode.

A supported identifier contains exactly twelve ASCII digits. This check does not query the APAAR registry, verify ownership or apply an invented government checksum. Internal matching checks submitted name/date-of-birth consistency and overlapping institutional records. Findings request review rather than declare fraud.

The evidence states are not submitted, format validated, institution attested, internal consistency checked, discrepancy flagged, external verification pending, externally confirmed and rejected/correction required. No default provider can assign externally confirmed. app/integrations defines the provider boundary and returns external verification pending by default.

Ed25519 proves that the trusted local demonstration issuer signed an untampered payload. It does not authenticate a government identity or validate a degree against DigiLocker. Screens, certificates and verifier output retain this boundary. No genuine government documents or production identifiers were used.
