The demonstration runs natively on Windows with existing Python 3.12 and Node.js. SQLite removes the need for a database service or Docker Desktop. Local statistical inference avoids paid AI dependencies. A deterministic seed creates 100 fictional institutions and 5,000 synthetic identities, with separate enrolment history and repeatable scenarios. Versioned REST services and a provider-neutral evidence boundary support later authorized integration. Production deployment requires approved government/SIS contracts, stronger key custody, authenticated recipient audiences, shared rate-limit storage, database migration hardening, load testing and an independent security assessment.
